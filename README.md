#  Predictive Maintenance Tracker for Engineering Labs

This project was developed as part of the **CSE370: Database Systems** course at **BRAC University**.

It is a **PHP–MySQL based web application** designed to manage laboratory equipment, monitor maintenance activities, and provide data-driven insights to improve operational efficiency.

---

##  Overview

Engineering labs rely heavily on equipment that requires regular monitoring and maintenance. This system helps:

* Track equipment usage and condition
* Record maintenance and downtime incidents
* Analyze trends to support predictive maintenance decisions

---

##  Features

*  Equipment Management (Add, Update, Delete records)
*  Maintenance Tracking system
*  Downtime incident logging
*  Analytical dashboards for insights
*  Role-based access (Admin / User)
*  Search and filter functionality

---

## Key Concepts Used

* Relational Database Design (MySQL)
* CRUD Operations
* Normalization and Data Integrity
* Role-Based Access Control (RBAC)
* Backend development using PHP

---

##  System Architecture

* **Frontend:** HTML, CSS (basic UI)
* **Backend:** PHP
* **Database:** MySQL

---

##  How to Run

1. Install **XAMPP / WAMP / LAMP**
2. Place the project folder inside:

   ```
   htdocs/
   ```
3. Import the database:

   * Open **phpMyAdmin**
   * Create a new database
   * Import the provided `.sql` file
4. Start Apache & MySQL
5. Open in browser:

   ```
   http://localhost/your-project-folder
   ```
